Code and results

The Python scripts that produce the numbers, figures and docx of the article, and the result files they write. Requirements: Python 3, NumPy, SciPy, pandas, Matplotlib, python-docx, pandoc.

Scripts

FileRole
compute2.py, compute.pyreading CoNLL-U, contracting the trees (punctuation removed), computing the flux (size, weight), segmenting the written corpora (resegment), ContentSUD (sud_to_content(..., chains=True))
fit.pymaximum-likelihood fit of the power law with exponential cut-off (Nelder–Mead, SciPy)
variants.pyTables 1 and 3: sentences of at least three words, mod:periph, illocutionary components, distributions and fits by corpus and length class → variants.json
lengths.pyTable 2: shares of short and long dependencies, observed and predicted by the fitted curve → length_shares.json
structure.pysections 4.3 and 4.4: weight on ContentSUD, pairs of disjoint dependencies by category of the governors and by relation, random orders of the same trees with the same total length, direction of the pending dependencies, bouquets (Table 4) → structure.json
bootstrap2.pystandard errors by resampling the sentences (200 replicates) → bootstrap2.json
extras.pyFigure 9, list of the sentences of weight 4 and 5 → extras.json, poids4.txt
figs.py, figs2.py, figs_en.pyfigures (FIGLANG=en for the English labels)
export_data.pyexport of the corpora as analyzed (sentences and illocutionary components)
mathdata_fr.py, mathdata.pydata of the Statistics page
make_docx.py, nbsp_pass.py, build_companion.pydocx in the journal's style, French non-breaking spaces, this site
pairs_content.pypairs of disjoint dependencies on ContentUD (French version of October)
get_grew_corpus.pyexport of a corpus from a grew-match server (UD @conv versions, CEFC-gold)

Results

  • variants.json: for each corpus, treatment (all relations, microsyntax only, variants) and length class, the number of sentences, the means, the distributions and the fitted parameters.
  • length_shares.json: Table 2.
  • structure.json: Table 4 and section 4.4 (pairs, relations, occurrences, examples).
  • bootstrap2.json: standard errors.
  • extras.json, pairs_content.json: results of the French version of October.
  • poids4.txt: the sentences whose flux weight reaches 4 or 5.

Reproduce

python3 variants.py          # Tables 1 and 3, distributions
python3 lengths.py           # Table 2
python3 structure.py         # Table 4, section 4.4
python3 bootstrap2.py        # standard errors
python3 extras.py            # Figure 9, poids4.txt
FIGLANG=en python3 figs2.py; python3 figs_en.py
python3 make_docx.py article_en.md article_flux_spoken_written.docx

The scripts expect the corpora at the paths of variants.CORPORA (to be adapted), and compute2.py, compute.py, fit.py in the same folder.
